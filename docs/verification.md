# Проверка полноты и открытые вопросы

## Топология

- [ ] Получить полную читаемую схему узлов, коммутаторов и портов.
- [ ] Подтвердить каждое соединение и его направление.
- [ ] Сверить логическую топологию с физическим стендом.

## Каналы и передача

- [ ] Установить единицы скорости и длины линий.
- [ ] Подтвердить, как моделируется распространение сигнала.
- [ ] Уточнить формат и размер пакета, включая служебные поля.
- [ ] Уточнить модель wormhole forwarding, буферов и flow control.

## Планирование

- [ ] Найти описание алгоритма и критерий оптимизации.
- [ ] Подтвердить семантику временного слота и цикла.
- [ ] Установить классы конфликтов и правила их разрешения.
- [ ] Найти описание формата экспорта/загрузки расписания, если он существует.

## Публикация

- [ ] Проверить право на публичное распространение исходных схем и выдержек.
- [ ] Удалить персональные данные и внутренние адреса.
- [ ] Проверить внутренние ссылки, сборку Jekyll и GitHub Pages.
- [ ] Убедиться, что каждый вывод имеет метку достоверности.

Незаполненные пункты не означают, что соответствующая функция отсутствует; они означают, что она пока не подтверждена доступными материалами.
