# Каналы и линии связи

В исходном описании используются дуплексные линии с параметрами скорости и длины. [РТО]

## Параметры линии

| Параметр | Описание | Статус |
|---|---|---|
| Скорость | Пропускная способность/скорость передачи, задаваемая в модели | [РТО]; единицы требуют сверки |
| Длина | Длина линии | [РТО]; единицы требуют сверки |
| Направления | Дуплексное соединение | [РТО] |
| Задержка распространения | Не указана численно | [Требует проверки] |
| Ошибки передачи | Модель ошибок не описана | [Требует проверки] |

## Временные составляющие

Для анализа передачи полезно различать:
- сериализацию данных на линии;
- распространение сигнала по среде;
- задержку обработки/коммутации;
- ожидание доступа к ресурсу;
- задержки, обусловленные расписанием.

Это аналитическая декомпозиция [Реконструкция], а не утверждение о точной формуле исходного приложения.

Не суммировать полную сериализацию всего пакета на каждом переходе, если используется конвейерная передача wormhole.
