# Wormhole routing

Wormhole forwarding — модель пересылки, при которой пакет разделяется на элементы передачи (например, flits), а продвижение по маршруту может быть конвейерным.

В материалах проекта wormhole routing назван как используемый сетевой контекст. [РТО] Само упоминание термина не подтверждает конкретную реализацию.

## Термины для чтения источников

- **Packet** — пакет сетевого уровня.
- **Flit** — единица передачи/управления потоком в wormhole-сетях.
- **Route** — последовательность каналов/коммутационных переходов.
- **Blocking** — задержка продвижения из-за недоступности следующего ресурса.

## Не переносить на проект без доказательств

Размер flit, глубина буфера, наличие виртуальных каналов, правила backpressure, алгоритм маршрутизации, арбитраж и deadlock avoidance остаются [Требует проверки].

## Временная оценка

Конвейерное продвижение означает, что полная сериализация пакета не обязательно повторяется на каждом переходе. Для точной оценки нужны модель каналов и правила продвижения, отсутствующие в доступном фрагменте.
