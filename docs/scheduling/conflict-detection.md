# Конфликты и ограничения расписания

Для анализа расписания полезно рассматривать ограничения на одновременное использование общих каналов и других сетевых ресурсов. Это аналитическая рамка [Реконструкция], а не описание подтверждённого алгоритма исходного планировщика.

## Возможные классы ограничений

- конкуренция за один и тот же направленный канал;
- несовместимые передачи через общий ресурс коммутации;
- ограничения порядка прохождения участков маршрута;
- временные зависимости между передачами;
- ограничения, связанные с пропускной способностью.

## Что нельзя утверждать без исходного алгоритма

Неизвестно, какие именно классы ограничений реализованы, как они обнаруживаются, как разрешаются и каким образом выбирается допустимое расписание.

Пересечение линий на рисунке не доказывает конфликт ресурсов. Для вывода нужны подтверждённые порты, направления и правила коммутации.
