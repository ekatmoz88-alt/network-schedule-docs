# Учебный пример расчёта передачи

Этот пример иллюстрирует только расчёт сериализации одного блока на одной линии. Он не воспроизводит исходный алгоритм планировщика.

## Исходные условные данные

- размер блока: 1000 байт;
- скорость одной линии: 100 Мбит/с;
- служебные поля, распространение сигнала и обработка коммутаторов не учитываются.

## Расчёт

`1000 байт × 8 = 8000 бит`

`T_ser = 8000 / 100 000 000 = 0,00008 с = 80 мкс`

<aside class="notice"><strong>[Учебный пример]</strong> Значения условные. Их нельзя переносить в описание реальной топологии или считать параметрами исходного проекта.</aside>

## Ограничения

При wormhole forwarding передача может идти конвейерно. Поэтому для маршрута из нескольких линий нельзя без модели конвейера умножать 80 мкс на число переходов. Для расчёта сквозной задержки нужны длины линий, скорость каждого сегмента, правила коммутации и flow control.
