# Временные слоты

Расписание временных слотов названо в доступном описании как результат работы планировщика. [РТО]

Однако само наличие временных слотов не определяет:
- фиксированную или переменную длительность слота;
- начало и конец цикла;
- возможность повторного использования слота;
- гранулярность расписания;
- синхронизацию часов;
- правила учёта задержек передачи.

| Есть расписание передачи по слотам | [РТО] |

| Периодичность цикла | [Требует проверки] |
| Привязка к аппаратному времени | [Требует проверки] |
| Формат хранения/экспорта | [Требует проверки] |

Не отождествлять временной слот планировщика с тайм-слотом канального протокола без прямого подтверждения.
